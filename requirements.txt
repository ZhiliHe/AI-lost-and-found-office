# --- optional extras --------------------------------------------------------
#
# The CLI already opens result photos with boxes drawn on them, so nothing
# below is needed for a working demo.
#
#   pip install gradio      # web UI (python -m src.app)
#                           # ~40 transitive deps; slow on a bad network
#   pip install requests    # only for scripts/download_model.py
#
# --- VLM backends: install ONLY the one you need ----------------------------
#
# Apple Silicon:
#   pip install -U mlx-vlm
#
# NVIDIA / CPU:
#   pip install -U "transformers>=4.57" torch accelerate qwen-vl-utils jinja2
#
# If you are working on the agent, retrieval or the UI you need NEITHER.
# Run `python scripts/make_dummy_index.py` and develop against that.

# --- speech (optional): the demo works by keyboard without any of this -------
#
#   pip install sounddevice
#   pip install mlx-whisper --no-deps          # Apple Silicon
#   pip install numpy scipy tqdm more-itertools tiktoken huggingface_hub
#
# --no-deps is deliberate. mlx-whisper declares numba and torch as hard
# requirements but uses numba in exactly one place - two @numba.jit functions
# for WORD-level timestamps, which a plain transcription never calls - and
# torch only in a weights-conversion path we never touch. There is no numba
# wheel for Python 3.14, so a normal install fails outright and speech dies for
# a reason that has nothing to do with speech. src/voice.py stands in a no-op
# decorator, and only when the real numba is genuinely absent.
#
# Speaking uses macOS's built-in `say` - no install, no download, no network,
# and it has good Korean and Chinese voices. Check yours with:
#
#   python -m src.voice
#
# The Whisper model is ~480MB. Fetch it once and point at the local copy so the
# demo never touches the network:
#
#   mkdir -p models/whisper-small-mlx && cd models/whisper-small-mlx
#   curl -L -C - -O https://huggingface.co/mlx-community/whisper-small-mlx/resolve/main/config.json
#   curl -L -C - -O https://huggingface.co/mlx-community/whisper-small-mlx/resolve/main/weights.npz
#   export WHISPER_MODEL=$PWD                 # or a smaller: whisper-base-mlx
